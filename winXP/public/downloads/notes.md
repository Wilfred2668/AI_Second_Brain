# Notes

This is a markdown file that will open in Notepad.

## Features
- Dynamic file loading
- Multiple file type support
- Windows XP styled interface

## File Types Supported
- Text files (.txt, .md, .log)
- PDF documents (.pdf)
- Images (.jpg, .png, .gif, .bmp)
